# 🖼️ Responsive Image Gallery

A modern and responsive image gallery website built using **HTML, CSS, and JavaScript**. The project allows users to browse images, filter them by category, and interact with the gallery through smooth transitions and navigation features.

## 📸 Preview

The website features a clean and visually appealing gallery layout with category filters and responsive image cards.

## ✨ Features

* 🖼️ Responsive image gallery layout
* 🏷️ Image category filtering
* 🔍 Lightbox image view
* ⬅️ Previous image navigation
* ➡️ Next image navigation
* ✨ Smooth transitions and animations
* 🖱️ Interactive hover effects
* 📱 Fully responsive design
* 🎨 Clean and modern UI

## 🗂️ Categories

The gallery includes different image categories such as:

* All
* Countryside
* City
* Cars
* Train
* Camera
* Typewriter

Users can select a category to display only the related images.

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling, layout, responsiveness, and animations
* **JavaScript** – Filtering, navigation, lightbox functionality, and interactions

The goal of this project was to create an interactive and visually attractive image gallery while practicing important frontend development concepts such as:

* CSS Grid and Flexbox
* Responsive web design
* DOM manipulation
* JavaScript event handling
* Image filtering
* Interactive navigation
* Smooth transitions and animations

## 📱 Responsive Design

The gallery is designed to work across different screen sizes, including:

* 💻 Desktop
* 📱 Mobile devices
* 📟 Tablets

The layout automatically adjusts to provide a better viewing experience on different devices.
